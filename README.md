# baimiao-writing · 白描写作技能

以极致白描为核心方法论的通用中文写作技能，面向 AI Agent 加载使用，也可供写作者直接参照。它覆盖小说、散文、杂文、议论文、教程、教材、科普、商务文案、工作总结、新媒体文稿等各类中文创作、改写与诊断场景。

这里的白描不是入门意义上的“写得平实”，而是一套以认知筛选、感官细节、克制留白、节奏控制、读者协同为骨架的高阶表达体系：删去形容词、副词、比喻和直接抒情之后依然立得住的文字，才见笔力。

## 核心主张

- 写作是认知的压缩与跨主体传输，不是自我表达的铺张。
- 白描的功夫在“不写什么”，留下的每个细节都要有功能。
- 情绪与判断不直接递给读者，给出可感的事实与动作，让读者自己走完最后一步。
- 中文是声调语言，韵律参与说服力，拗口处往往也是逻辑问题处。
- 朴素具有跨时间、跨文化的穿透力，修辞带有时代折旧。

## 九步工作流

定靶（读者与唯一传输目标）→ 取材（感官细节与动作事实先行）→ 立骨（名动结构搭骨架）→ 藏意（情绪与判断转译）→ 删减（无功能细节移除）→ 调律（长短句与虚词节奏）→ 适配文体 → 过质量门 → 保真验证（读者复述测试）。详见 SKILL.md。

## 安装

将 `baimiao-writing` 整个目录放入 Agent 的用户技能目录（如 `.user_skills/baimiao-writing/`），保持上述目录结构不变，重启或刷新技能列表后即可被自动识别触发。

## 成稿体检脚本

脚本只依赖 Python 标准库，支持文件路径、标准输入与 JSON 三种调用方式，输出句长节奏、“的地得”密度、程度副词、抽象情绪词、套话痕迹、绝对化表述等指标，只提供修改线索，不自动改稿。

```bash
python3 scripts/baimiao_lint.py 文稿.txt
cat 文稿.txt | python3 scripts/baimiao_lint.py
python3 scripts/baimiao_lint.py 文稿.txt --json
```

脚本中的阈值均为写作训练的经验参数，按文体浮动，不替代人工判断。

## 适用与边界

适用于一切以中文进行的表达工作：叙事类文字重感知层白描，说理类文字重共识锚定与事实切片，说明类文字重动作序列还原。技能不提供“一键生成爆款”的模板，它要求作者先完成观察与判断，再谈表达。
